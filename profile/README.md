The all-in-one social media scheduler, with a video editor built in. Plan your posts on a calendar and send them on time to YouTube, TikTok, Instagram, Facebook, Threads, X, LinkedIn, Bluesky and Pinterest.

- **[plan-video](https://github.com/plan-video/plan-video)**: the whole app: the dashboard, the editor, the services that post for you and the database. Open source under AGPL-3.0, and you can host it yourself.
- **[plan.video](https://plan.video)**: the hosted version runs the same code, with nothing to set up.
